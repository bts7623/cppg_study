숫자 연상 묶음

위 표의 숫자를 이야기로 묶은 것
72시간 = 3일 = “유출은 주말 안에”통지·신고·가능성 통지 전부 72시간. 금요일에 터지면 월요일 아침 전에 끝내야 한다고 그림 그리기. 못 알리면 게시판에 30일(한 달 내내 공지).
10일은 “정보주체 요구”의 숫자열람·정정삭제·처리정지 + 사전 실태점검 시정권고 수락 통지까지 전부 10일. 정보주체가 “열흘 안에 해줘” 한다고 묶기. 자동화 결정만 30일(기계가 결정한 건 사람이 다시 보느라 오래).
보호위 9·3 / 조정위 30·2 / 소위 3 — “구삼(9·3) 삼공이(30·2) 삼”작은 위원회(9명)가 오래(3년), 큰 위원회(30명)가 짧게(2년). 소위원회는 3명 전원. 기본계획도 3년, 인증도 3년, 기록 보관도 3년 — “3은 보호위원회의 숫자”.
5·50·100 “오만 민감, 오십만 연계, 백만 일반”영향평가 대상. 같은 5만·100만이 ‘대규모 처리자’(출처통지·내역통지·CPO 신고·전송요구) 기준으로도 반복 등장 — 5만은 항상 ‘민감·고유식별’과, 100만은 ‘일반’과 짝.
3%·20억 → 10%·50억 “삼이(3·20) 십오(10·50)”과징금 일반 vs 가중. 매출 없으면 20억·50억. 가산금 연 6%·60개월은 “육(6)육(60)”. 망법 광고성 과징금도 6%.
형벌 계단 10·5·3·2 / 과태료 계단 5·3·1·0.5징역 10년(1억)·5년(5천)·3년(3천)·2년(2천)은 “숫자가 같이 내려감”. 과태료는 5천·3천·1천·5백 — 최고 5천은 ‘목욕탕 카메라’ 둘뿐.
손해배상 5배·300만 / 보험 10억·1만명“오(5)배로 삼백(300)”, 보험 가입은 “십억 매출에 만 명” — 둘 다 충족해야 가입 대상.

순서를 묻거나 “다음 단계는?”으로 나옴. 번호 순서 그대로 암기.

유출등 사고 대응 절차

제34조, 시행령 제39조·제39조의2·제40조
  1. 인지 — 유출등(분실·도난·유출·) 또는 유출 을 알게 된 때
  2. 긴급조치 — 접속경로 차단, 취약점 보완, 회수·삭제 등 피해 확산 방지 (제34조 제3항)
  3. 통지 — 내 서면등으로 정보주체에게 7가지(항목·시점경위·피해최소화방법·대응조치·담당부서··기타). 미확인 시 확인된 내용으로 후 추가 통지
  4. 신고 — 1천명·민감/고유식별·외부 불법접근 중 하나면 내 보호위원회 또는 . 회수·삭제로 침해 가능성 현저히 낮아지면 생략 가능
  5. 갈음 — 연락처 모르면 홈페이지 게시 / 가능성 통지 후 미유출 확인 시 그 사실 통지
  6. 사후 — 원인 분석·재발 방지, 손해배상(5배·300만원) 대비, 과징금(유출등 제29조 다했으면 면제) 대응
인기 폭발 긴급 통신, 갈아타긴 사후에인지 → 긴급조치 → 통지 → 신고 → 갈음 → 사후. 연상: 유출이 터지면 인기 폭발하듯 전화통(통지·신고)이 불나고, 연락 안 되는 사람은 홈페이지로 갈아타고(갈음), 뒷정리는 사후에.
신고 3유형은 천·민·외: “천 명의 민간인이 외부(해커)에게” — 1천명 / 민감·고유식별 / 외부 불법접근. 통지는 1명이라도, 신고는 이 셋 중 하나.

개인정보 영향평가(PIA) 절차

제33조, 시행령 제35조~제38조
  1. 대상 판단 — 전자적 파일 중 또는 운용체계 변경
  2. 보호위원회 지정 에 의뢰 (최근 5년 2억 실적·전문인력 10명)
  3. 평가기관이 평가기준(정보 종류·수·침해가능성, 안전조치 수준, 위험요인별 조치, 의무 위반 요소)으로 분석 → (대상·범위, 분야·항목, 분석, 개선계획, 결과, 요약) 작성
  4. 공공기관의 장은 파일 운용·변경 에 보호위원회에 제출
  5. 보호위원회 (승인 아님), 요약 공개 가능
  6. 개인정보파일 시 결과 첨부
대의(大義)로 평가서 제출하니 의견 달고 등록대상 → 의뢰 → 평가 → 제출 → 의견 → 등록. 연상: 공공기관이 ‘대의명분’으로 평가기관에 맡기고, 보호위원회는 승인이 아니라 “의견”만 한 줄 달아준 뒤, 파일 등록 때 그 평가서를 첨부.
대상 숫자 5·50·100 = 민·연·일: “오(5)만 민감한 사람, 오십(50)만 연결하면, 백(100)만 일반인” — 민감·고유식별 5만 / 연계 50만 / 일반 100만.

가명정보 결합·반출 절차

제28조의3, 시행령 제29조의3
  1. 결합신청자가 에 결합신청서 + 서류(사업자등록, 대상 가명정보, 결합 목적 증명)
  2. 전문기관이 특정 개인을 알아볼 수 없도록
  3. 반출하려면 기관 내 안전 공간에서 처리
  4. 심사 → 전문기관장 승인(관련성·식별 불가·안전조치 계획)
  5. 반출 후 처리 기록 작성, 파기 후 보관
결혼 절차로 외우기: 신청 → 결혼 → 가명(혼인 전 가칭) → 심사 → 기록(가족관계등록)신청 → 결합 → 가명·익명 처리 → 심사·승인 → 기록. 연상: 서로 다른 두 집안(처리자)의 가명정보가 ‘결혼’하려면 혼인신고처(결합전문기관)에 신청하고, 결합한 뒤 밖으로 나갈 땐 신분을 가명·익명으로 바꿔 반출심사위원회 심사를 받고, 기록은 파기 후 3년 보관.

분쟁조정 절차

제43조~제49조
  1. 정보주체·처리자가 분쟁조정위원회에 (공공기관은 조정에 응해야)
  2. 자료 요청·출석 요구·(2023)
  3. 조정 전
  4. 신청일부터 내 조정안 작성 (침해 중지, 원상회복·손해배상, 재발방지)
  5. 당사자 내 수락 여부 통지, 무응답 = 수락

접속기록 (고시 제8조)

시행령 제30조 제1항 제5호 · 고시 제8조
취급자 계정접속일시접속지 정보(IP)처리한 정보주체 정보수행업무
접속기록은 이상 보관·관리한다. 단, 이상 정보주체의 고유식별·민감정보를 처리하거나 인 경우 이상. 이상 점검하고, 개인정보를 한 경우 그 사유를 확인한다. 위·변조·도난·분실 방지를 위해 안전하게 보관하고 에 백업.
계·일·지·주·업 — “계일지, 주업이 뭐냐”접속기록 5항목: 계정·접속일시·접속지·정보주체·수행업무. 보관 1년(기본)·2년(5만 민감/고유식별·기간통신), 점검 월 1회. 취급자의 주민번호·비밀번호는 접속기록 항목이 아님.

총칙·원칙

개인정보란 개인에 관한 정보로서, 다른 정보와 하여 알아볼 수 있는 정보를 포함하며, 결합 가능성은 등을 합리적으로 고려한다.
개인정보처리자는 익명처리가 가능하면 으로, 익명으로 목적 달성이 안 되면 으로 처리될 수 있도록 하여야 한다.
개인정보 보호의 날은 매년 이다. 보호위원회는 소속이며 마다 기본계획을 수립한다.
